Lab 09
DOM and Events

8 Exercise · Mỗi bài có trang chạy riêng và mã nguồn tương ứng.

9.1 · Basic DOM Selection Thử các API chọn DOM; đọc HTML/text/attribute và thay đổi class, style. 9.2 · DOM Family Relations Duyệt firstChild, nextSibling, parentNode, childNodes; phân biệt text node và element. 9.3 · Modifying the DOM createElement, createTextNode, appendChild và removeChild. 9.4 · Simple Event Handling Click ẩn/hiện với transition, setTimeout; mouseover/mouseout đổi ảnh xám. 9.5 · Responding to Load Events Đặt script trong head, dùng load để đọc div sau khi DOM sẵn sàng. 9.6 · Debugging Events Theo dõi e.type, e.target.id và biến cục bộ; đặt breakpoint qua DevTools. 9.7 · Working with Forms Focus đổi nền vàng, blur trả nền trắng cho các trường biểu mẫu. 9.8 · Form Validation Chặn gửi khi trường rỗng, hiển thị danh sách lỗi trong trang và thử dữ liệu hợp lệ.
