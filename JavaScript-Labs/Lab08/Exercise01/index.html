Lab 08 / Exercise 01

Enabling/Disabling JavaScript

Phân biệt kết quả khi bật và tắt JavaScript bằng script và noscript.

Đang kiểm tra JavaScript…

Bật/tắt JavaScript trong cài đặt quyền trang web của trình duyệt rồi tải lại. Khi tắt, chỉ thông báo noscript xuất hiện.

Xem mã nguồn & cách kiểm tra

Mở main.js và index.html . Dùng F12 → Console / Sources để kiểm tra biến và đặt breakpoint.
