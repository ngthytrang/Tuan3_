11 Exercise · Mỗi bài có trang chạy riêng và mã nguồn tương ứng.

8.1 · Enabling/Disabling JavaScript Phân biệt kết quả khi bật và tắt JavaScript bằng script và noscript. 8.2 · Embedded JavaScript Nhúng script trong head, hiển thị hộp thoại Hello World!. 8.3 · External JavaScript Tách hello.js; document.write, biến count và toán tử tăng. 8.4 · Using noscript Dùng noscript để hiển thị nội dung thay thế khi JavaScript bị tắt. 8.5 · Using the Browser Console Sửa lỗi doccumment; kiểm tra count, output, temp; log, warn và error. 8.6 · Using Built-in JavaScript Objects So sánh String object và string literal; Date, Math.PI, sqrt, random. 8.7 · Arrays push, unshift; vòng lặp và điều kiện tạo lịch 30 ngày bắt đầu Chủ nhật. 8.8 · JavaScript Functions Hàm outputBox có tham số, trả chuỗi; 5 hộp và phạm vi biến. 8.9 · Functions as Objects Hàm là đối tượng: hàm lồng, biểu thức hàm, hàm ẩn danh truyền làm callback tính thuế. 8.10 · Creating JavaScript Objects Object constructor, literal, bracket notation; hai đơn hàng có total và output. 8.11 · Arrays of Objects Mảng Country, truy cập thuộc tính động bằng bracket notation và vòng for…in.
