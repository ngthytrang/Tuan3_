Lab 10
jQuery

10 Exercise · Mỗi bài có trang chạy riêng và mã nguồn tương ứng.

10.1 · Setup jQuery Nạp jQuery; CDN tùy chọn có fallback thư viện cục bộ. 10.2 · Basic Selectors val, html, attr, css và addClass bằng bộ chọn ID, thẻ, class. 10.3 · Advanced Selectors Bộ chọn :password, :nth-child(4n) và label:contains("word"). 10.4 · jQuery Listeners Document ready; nối on mousemove, mouseleave, click; off để gỡ mousemove. 10.5 · Inserting DOM Elements Thử after, before, append, prepend, appendTo, prependTo, insertBefore. 10.6 · Simple jQuery Animation Sáu hiệu ứng fadeIn, fadeOut, fadeToggle, slideDown, slideUp, slideToggle. 10.7 · More jQuery Animation Tạo preview ảnh medium, chú thích; gray, fadeIn; di chuyển và xóa khi rời ảnh. 10.8 · Complex Animations Chuỗi animate thay đổi left, opacity, height, top theo thứ tự. 10.9 · GET Requests GET bất đồng bộ; kiểm tra success, duyệt dữ liệu JSON bằng $.each. 10.10 · jqXHR Handling jqXHR done/fail/always, chỉ báo tải, chống trùng kết quả và kiểm thử lỗi.
