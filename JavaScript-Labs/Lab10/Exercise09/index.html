GET Requests

GET bất đồng bộ; kiểm tra success, duyệt dữ liệu JSON bằng $.each.

Dữ liệu cục bộ là bộ dữ liệu minh họa, không giả danh phản hồi từ dịch vụ cũ. Mở qua HTTP (không dùng file://) để thực hiện AJAX.

Đang tải dữ liệu…

    Xem mã nguồn & cách kiểm tra

    Mở main.js và index.html . Dùng F12 → Console / Sources để kiểm tra biến và đặt breakpoint.
